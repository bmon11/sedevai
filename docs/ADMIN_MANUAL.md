# Сэдэв.мн — ажилтны гарын авлага

Сэдэв.мн нь мэдээллийн сайтуудаас нийтлэл цуглуулж, хиймэл оюун (Gemini)-аар гол сэдвүүдийг сонгон задлан шинжилж, 6 цаг тутам шинэ багц нийтэлдэг. Энэ гарын авлага нь удирдлагын хэсгийг (`/admin`) ашиглах ажилтнуудад зориулагдсан.

## 1. Нэвтрэх

1. `https://<сайт>/admin` хаягаар орно.
2. **Нэвтрэх нэр** болон **Нууц үг**-ээ оруулаад **Нэвтрэх** дарна.
3. Нэвтэрсэн төлөв 7 хоног хадгалагдана. Гарахдаа баруун дээд буланд байгаа зураг → **Гарах**.

**Нууц үг солих:** баруун дээд буланд байгаа зураг → **Нууц үг солих** → одоогийн болон шинэ нууц үгээ (8+ тэмдэгт) оруулна.

**Нууц үгээ мартсан бол** админ эсвэл супер админд хандана. Тэд таны бүртгэлд шинэ нууц үг тохируулж өгнө.

**"Account is disabled"** гэж гарвал таны бүртгэлийг түр хаасан байна — админд хандана уу.

Товчоор:

- **Супер админ** — бүх зүйл, үүнд бусад админ, супер админы бүртгэл.
- **Админ** — системийн тохиргоо, эх сурвалж; редактор, модератор, сэтгүүлчийн бүртгэл.
- **Редактор** — агуулгын хариуцагч: сэдэв засах, нуух, ажиллагаа эхлүүлэх, задлах цэгүүд, сошиал аккаунтуудыг тохируулах.
- **Модератор** — нийтлэгдсэн сэдвийг хянаж, зохисгүйг нуух.
- **Сэтгүүлч** — сэдвийн гарчиг, тайлбар, ангиллыг засварлах.

## 3. Сэдвүүд

Нийтлэгдсэн бүх сэдэв, хамгийн шинэ нь эхэндээ.

| Багана          | Утга                                                         |
| --------------- | ------------------------------------------------------------ |
| **Нийтэлсэн**   | Сэдэв үүссэн огноо, цаг (Улаанбаатарын цагаар)               |
| **Сэдэв**       | Гарчиг (асуулт хэлбэрээр) ба яагаад сонгогдсон шалтгаан      |
| **Ангилал**     | Улс төр, Эдийн засаг, Нийгэм, Дэлхий, Спорт, Соёл, Технологи |
| **Харагдах**    | Уншигчдад харагдаж байгаа эсэх                               |
| **Засварласан** | Хамгийн сүүлд зассан эсвэл нуусан ажилтны нэвтрэх нэр        |

- **Нээх** — сэдвийн хуудсыг уншигчийн сайтад шинэ цонхонд нээнэ.
- **Засах** — гарчиг, сонгосон шалтгаан, ангиллыг засна. Алдаатай, төөрөгдүүлсэн гарчиг, буруу ангиллыг засахад хэрэглэнэ. Задлан шинжилгээний (Товчхондоо, Байр суурь г.м.) текстийг засах боломжгүй.
- **Харагдах** унтраалга — унтраавал сэдэв нүүр хуудас, архиваас алга болж, холбоос нь "олдсонгүй" гэж гарна. Дахин асаавал буцаж харагдана. Устгагдахгүй.

Өөрчлөлт уншигчийн сайтад **5 минутын дотор** харагдана.

## 3а. Тайлан

Нийтлэгдсэн дугааруудын аналитик: өдөр бүр ямар үйл явдал, ямар ангилал халуун байсныг харуулна. Баруун дээд буланд **7 / 14 / 30 / 90 өдөр** сонгоно (Улаанбаатарын цагаар).

**Үйл явдал гэж юу вэ?** Дугаар бүр сэдвүүдээ шинээр үүсгэдэг тул нэг мэдээ олон дугаарт өөр сэдэв болж гардаг. Тайлан тэдгээрийг нэг **үйл явдал** болгон нэгтгэнэ: сүүлийн 48 цагт гарсан сэдэвтэй ижил эх сурвалж (2+ нийтлэл/пост, эсвэл тал хувь) хуваалцвал нэг үйл явдал гэж үзнэ.

**Оноо** = сэдвийн 🔥 халуун оноо (0–100). Халуун оноо гараагүй хуучин дугаарт сэдвийн дарааллаар тооцно (1-рх нь 100).

| Хэсэг                     | Юу харуулах                                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Дээд 4 хайрцаг            | Дугаар ба сэдвийн тоо, үйл явдлын тоо (шинээр гарсан нь), тэргүүлсэн ангилал, хамгийн халуун                                   |
| **Ангиллын хандлага**     | Өдөр бүр ангилал тус бүр хэр халуун байсан. **Халуун оноо** / **Үйл явдлын тоо** сэлгэнэ                                       |
| **Ангиллын хувь**         | Хугацааны нийт онооноос ангилал тус бүрийн эзлэх хувь                                                                          |
| **Үйл явдлын хандлага**   | Удаан яригдсан 8 үйл явдлын оноо дугаар бүрээр — өсч байна уу, буурч байна уу                                                  |
| **Өдрийн халуун сэдвүүд** | Өдөр бүрийн хамгийн халуун 5 үйл явдал, ангилал, оноотой                                                                       |
| **Бүх үйл явдал**         | Бүх үйл явдал: ангилал, анх гарсан цаг, хэдэн дугаар, хэдэн өдөр, дээд оноо                                                    |
| **Зардал**                | Өдөр бүрийн сошиал (twitterapi.io, ScrapeCreators) ба AI (Gemini) зардал $-аар; нийт дүн, сошиал хүсэлт, кредит, AI токены тоо |

Зардлыг жагсаалтын үнээр тооцно: twitterapi.io — твит бүр $0.00015, ScrapeCreators — **Тохиргоо**-ны "1 кредитийн үнэ", Gemini — загварын үнэ. Энэ боломж нэмэгдэхээс өмнөх ажиллагааг $0 гэж харуулна.

Үйл явдлын гарчиг дээр дарвал хамгийн сүүлийн сэдвийг уншигчийн сайтад шинэ цонхонд нээнэ. Нуусан сэдэв тайланд орохгүй.

## 3б. Хүмүүс (Редактор, Админ)

Уншигчийн сайтын **Хүмүүс** хэсэгт гарах олон нийтийн зүтгэлтнүүдийн жагсаалт. Мэдээ цуглуулах ажил шинэ нийтлэл бүрээс тэднийг хайж, AI нь хэн, ямар үүрэгтэй (гол сэдэв / иш татсан / дурдсан), ямар өнгөөр гарсныг тэмдэглэнэ.

- **Нэмэх** / **Засах**: овог нэр, товч нэр (мэдээнд бичигддэгээр, жишээ нь `Н.Учрал`), хаяг (`/people/uchral`, дараа нь өөрчлөгдөхгүй), албан тушаал, товч танилцуулга.
- **Хайх нэрс** — таслалаар тусгаарласан нэрийн үндэс, том үсгээр: нэр хувирдаг бол хувирах хэсгийг хас (`Баттулга` → `Баттулг`, `Оюун-Эрдэнэ` → `Оюун-Эрдэн`). Жижиг үсгээр бичигдсэн үгийг (жишээ нь "учрал") хайхгүй.
- **Албан тушаалыг үргэлж шинэчил**: ижил нэртэй хүмүүсийг AI овгийн үсэг, албан тушаалаар ялгадаг. Мэдээнд нэр өөр овгийн үсэгтэй л бичигдсэн бол (Р.Пүрэвдагва ≠ Б.Пүрэвдагва) өөр хүн гэж үзнэ.
- Унтраавал профайл уншигчдад харагдахгүй, шинэ мэдээнээс хайхаа болино.
- Шинэ нэр зөвхөн цаашид ирэх мэдээнд үйлчилнэ. Өмнөх мэдээнд хэрэгжүүлэх бол хөгжүүлэгчид хандана.
- "Хэвлэлийн өнгө" нь хэвлэл тухайн хүнийг хэрхэн харуулсныг заана, Сэдэв.мн-ийн үнэлгээ биш.

## 4. Ажиллагаа

Систем дөрвөн тусдаа ажлыг өөр өөрийн хуваарьтай (**Тохиргоо → Хуваарь**) автоматаар ажиллуулна:

| Ажил    | Юу хийх                                                                                   | Зардал              | Анхдагч хуваарь                                    |
| ------- | ----------------------------------------------------------------------------------------- | ------------------- | -------------------------------------------------- |
| Вэб     | Мэдээний сайтуудаас шинэ нийтлэл цуглуулна                                                | Үнэгүй              | Цаг тутам, 07–21 цаг (шөнө амарна)                 |
| Сошиал  | Аккаунтуудын шинэ постыг татна (X — twitterapi.io, Facebook/Threads — ScrapeCreators)     | Үйлчилгээний кредит | Цаг тутам, 08:00–22:00                             |
| Нийтлэх | Цуглуулсан мэдээнээс сэдэв сонгож, задлан шинжилж нийтэлнэ                                | Gemini токен        | Цаг тутам 08:10–22:10 (сошиалаас 10 минутын дараа) |
| Гадаад  | Гадаадын 22 сайтаас цуглуулж, сэдэв сонгон монголоор задлан шинжилж Гадаад табад нийтэлнэ | Gemini токен        | 3 цаг тутам, 08:30–20:30                           |

Бүх хуваарь Улаанбаатарын цагаар. Cron: сошиал `0 8-22 * * *`, нийтлэх `10 8-22 * * *`, гадаад `30 8-20/3 * * *`.

- Жагсаалт: эхэлсэн цаг, ажил (Вэб / Сошиал / Нийтлэх), эхлүүлсэн (Хуваарь / Гараар), төлөв, үе шат, нийтлэл эсвэл постын тоо, сэдвийн тоо, зарцуулсан токен. Дээрх табаар нэг ажлыг шүүнэ.
- **Вэб цуглуулах**, **Сошиал цуглуулах**, **Нийтлэх** — тухайн ажлыг одоо эхлүүлнэ. Ажил бүрээс нэг удаад нэг л явна; өөр ажлууд зэрэг явж болно. Яаралтай шинэ багц хэрэгтэй бол эхлээд **Вэб цуглуулах**, дуусмагц **Нийтлэх** дарна.
- **Алгассан** төлөв — хуваарьт нийтлэх ажил өмнөх багцаас хойш хангалттай шинэ мэдээ олоогүй тул токен зарцуулалгүй зогссон. Уншигчид өмнөх багцаа харсаар байна. Гараар дарсан **Нийтлэх** хэзээ ч алгасахгүй.
- Хэмнэлт: нийтлэх ажил зөвхөн шинэ мэдээг AI-д өгч, өмнөх сэдвүүдийн үргэлжлэл бол тэдэнд нэгтгэнэ. Шинэ эх нэмэгдээгүй сэдвийн задлан шинжилгээг (засвартай нь) дахин бичилгүй хуулна — "N дахин" гэж харагдана.
- Мөр дээр дарвал дэлгэрэнгүй: тухайн ажлын үе шат (Вэб: Цуглуулах; Сошиал: Сошиал; Нийтлэх: Бүлэглэх → Сонгох → Задлан шинжлэх → Нийтлэх), сонгосон сэдвүүд (эх, пост, hot оноотой), эх сурвалж бүрийн тайлан, **Сошиал тайлан** (платформ бүрийн үйлчилгээ, шинэ / нийт пост, хүсэлт, кредит, $ зардал, алдаа), лог. Лог дээр сошиал ажил бүр "Social usage: … requests, … credits, $…", нийтлэх ажил "LLM usage: … calls, … tokens, $…" мөр бичнэ.
- **Гадаад мэдээ** — гадаадын сайтуудыг цуглуулаад шууд Бүлэглэх → Сонгох → Задлан шинжлэх → Нийтлэх хийнэ (хүн таних, сошиал алхамгүй). Монгол багцаас тусдаа; уншигчид нүүрний **Гадаад** табаас үзнэ. Хамрах хугацаа, сэдвийн тоо, шинэ нийтлэлийн доод тоог **Тохиргоо → Гадаад мэдээ**-ээс тохируулна.
- Алдаа гарвал улаанаар харагдана. Шалтгааныг арилгаад **Үргэлжлүүлэх** дарна — дууссан ажил хадгалагдана. Энэ хооронд уншигчид өмнөх багцаа харсаар байна.

## 5. Эх сурвалж (Админ)

Мэдээ цуглуулах сайтууд.

- Унтраалгаар сайтыг дараагийн ажиллагаанаас хасна / нэмнэ.
- **Нэмэх / Засах** — сайтын тохиргоо. Хадгалахаас өмнө **Шалгах** дарж, гурван жишээ нийтлэл ✓ болон огноотой гарч байгааг шалгана.
- 74 сайт бий (2026-10-12-нд бүгдийг шалгасан). Ажиллахгүй, мэдээний бус эсвэл 7+ хоног шинэ мэдээгүй 17 сайтыг хасаж унтраасан.
- **Selector-гүй сайт нэмэх:** нэр, slug, сайтын хаяг, нүүр (эсвэл ангиллын) хуудсаа оруулаад **Нийтлэлийн замын загвар** болон текстийн selector-ыг хоосон үлдээж **Шалгах** дарна. Загваргүй бол сайтын RSS-ийг, байхгүй бол нийтлэл шиг харагдах (дугаартай, огноотой эсвэл урт slug-тай) холбоосыг авна. Selector-гүй бол нийтлэлийн текстийг автоматаар олно. Жишээнд огноо гарахгүй бол **Огнооны selector**-т огноо харуулдаг элементийг (жишээ нь `.post-date`), буруу хуудас орж ирвэл загвар (жишээ нь `/n/\d+`) тавина.
- **Жин** (0.5–3) — сайтын нэр хүнд. Сэдвийн hot оноонд тухайн сайтын нийтлэл хэр их нөлөөлөхийг заана: 0.5 жижиг, 1 энгийн, 2 том, 3 тэргүүлэх хэвлэл.
- **Жин тооцоолох** — бүх сайтын жинг сүүлийн N хоногийн (анхдагч 30) өгөгдлөөс дахин тооцно. **Тооцоолох** нь хуучин → шинэ жинг хадгалахгүйгээр харуулна, **Хадгалах** нь хадгална. Олон нийтлэгдсэн сэдэвт орсон, сэдвийг эхэлж мэдээлдэг, нийтлэлийнх нь ихэнх нь сэдэвт ордог сайтын жин өснө. Өгөгдөл багатай сайт анхны түвшиндээ (шинээр нэмсэн сайт 1) ойр үлдэнэ. Гараар тавьсан жинг дарж бичнэ — сард нэг удаа хангалттай.
- **Бүс** — _Монгол_ (Шуурхай, Халуун таб, Вэб + Нийтлэх ажил) эсвэл _Гадаад_ (Гадаад таб, Гадаад мэдээ ажил). Жагсаалтад гадаад сайт «Гадаад» шошготой. 22 гадаад сайт (BBC, The Guardian, Al Jazeera, DW, France 24, CBS, The Independent, Euronews, Politico Europe, CNBC, SCMP, CNA, Yonhap, The Diplomat, TASS, The Moscow Times, Asia Times, TechCrunch, The Verge, Ars Technica, BBC Sport, ESPN) 2026-10-19-нд шалгагдсан; бүгд RSS-ээр уншигдана. Төлбөртэй (Reuters, Bloomberg, FT, NYT) болон ботыг хаадаг сайтыг оруулаагүй. **Жин тооцоолох** зөвхөн монгол сайтуудад хамаарна.
- Тохиргооны талбаруудын дэлгэрэнгүй: backend `docs/USER_GUIDE.md`.

## 5а. Сошиал (Редактор, Админ)

Facebook, X, Threads дээрх сэтгүүлч, пейж, нөлөөлөгчдийн аккаунтууд. Ажиллагаа бүр тэдгээрийн постыг цуглуулж, сэдэв сонгоход ашиглаж, уншигчийн **Сошиал** хуудсанд харуулна. Платформ бүрийн постыг **Тохиргоо**-нд сонгосон үйлчилгээгээр татна: X — **twitterapi.io**, Facebook ба Threads — **ScrapeCreators**. Серверт тухайн үйлчилгээний түлхүүр (`TWITTERAPI_IO_KEY`, `SCRAPECREATORS_KEY`) тохируулаагүй бол тэр платформ алгасагдана (Сошиал тайланд "skipped").

**Зөвхөн шинэ пост татна.** Аккаунт бүрийн сүүлд харсан постыг хадгална. Дараагийн ажил зөвхөн сүүлийн ажиллагаанаас (давхцлын цагийг хассан) хойших постыг авна: X дээр хэд хэдэн аккаунтыг нэг хайлтаар, Facebook дээр 3 постоор хуудаслаж, сүүлийн ажиллагаанаас хуучин пост гармагц зогсоно. Threads сүүлийн ~20–30 постоо буцаадаг тул хуучныг нь хаяна. Шинээр нэмсэн аккаунтын постыг хамрах хоногийн эхнээс (аккаунт бүрээс дээд тал нь "Аккаунт бүрээс пост") татна.

Нэг зэрэг дээд тал нь 10 хүсэлт явуулна; үйлчилгээ "хэт олон хүсэлт" (429) гэвэл түр хүлээгээд дахин оролдоно.

- Дээд талын **Бүгд / Facebook / X / Threads** табаар аккаунт болон постыг платформоор ангилж харна (хаалтанд аккаунтын тоо).
- **Аккаунт нэмэх** — платформ, төрөл (сэтгүүлч, пейж, нөлөөлөгч, хэвлэл мэдээлэл, албан ёсны), профайлын хаяг (жишээ нь `https://www.facebook.com/ikon.mn`, `https://x.com/нэр`, `https://www.threads.com/@нэр`), нэр.
- **Жин** (0.5–3) — аккаунтын нэр хүнд, итгэл. Постын оноог шууд үржүүлнэ. Дагагч олонтой ч найдваргүй аккаунтад бага, нэр хүндтэй сэтгүүлчид өндөр жин өгнө.
- **Дагагч** — X, Threads автоматаар шинэчилнэ. Facebook дагагчийн тоог өгдөггүй тул гараар оруулна.
- **Шалгах** — хадгалахгүйгээр сүүлийн 5 постыг татаж харуулна (1–2 кредит зарцуулна). Пост гарч байвал хадгална.
- **Постууд** таб — цуглуулсан постууд, like, сэтгэгдэл, түгээлт, оноо.
- **Дундаж идэвх** — аккаунтын сүүлийн 30 постын дундаж (медиан) идэвх. Пост үүнээс их идэвх авбал "трэнд" гэж тооцогдоно.

**Hot оноо хэрхэн тооцогддог вэ?**

- Постын идэвх = like + 2×сэтгэгдэл + 3×түгээлт (+ үзэлтийн 1%).
- Постын оноо = идэвхийн логарифм × аккаунтын жин × дагагчийн логарифм × (дундаж идэвхээсээ хэр давсан)-ын язгуур.
- Сэдвийн hot оноо (0–100) = мэдээний хамрах хүрээ (сайтын жингээр; сайт бүр нэг удаа, өөр сайтын нийтлэлийг хуулбарласан нь 30%) 50% + сошиал идэвх (олон аккаунт нэг вирус постоос илүү) 35% + хурд (сүүлийн 24 цаг) 15%. Хувийг **Тохиргоо**-нд өөрчилнө.
- Шинэ зүйл илүү оноо авна: оноо 24 цаг тутам хоёр дахин буурна.
- Сэдвүүд нүүр хуудсанд hot оноогоор эрэмбэлэгдэнэ.

## 6. Задлах цэгүүд (Редактор, Админ)

Сэдэв бүрийг ямар өнцгөөс задлахыг тодорхойлно (Товчхондоо, Юу болов?, Тоон баримт, Яагаад анхаарал татаж байна?, Үйл явдлын дараалал, Байр суурь, үзэл бодол г.м.).

- 2026-10-13-нд "Шалтгаан, суурь нөхцөл"-ийг "Яагаад анхаарал татаж байна?"-д, "Сайн ба муу тал"-ыг "Байр суурь, үзэл бодол"-д нэгтгэсэн. Уншигчид эх сурвалж (нийтлэлийн жагсаалт, хэвлэлийн нэр, тоо) харагдахгүй; эх сурвалжийг зөвхөн админд харна.

- Сумаар сэдвийн хуудсан дээрх дарааллыг өөрчилнө; унтраалгаар идэвхжүүлнэ.
- **Гарчиг** — уншигчид харагдах нэр; **Хэлбэр** — харагдах загвар; **AI-д өгөх заавар** — хиймэл оюунд юу бичихийг тайлбарласан заавар.
- Өөрчлөлт **дараагийн ажиллагаанаас** хэрэгжинэ. Нийтлэгдсэн сэдвүүд өөрчлөгдөхгүй.

## 7. Тохиргоо (Админ)

**Хуваарь** — Вэб, Сошиал, Нийтлэх ажил тус бүрийн унтраалга ба давтамж: бэлэн сонголт (цаг тутам, цаг тутам 07–21 цаг, цаг тутам 08–22 цаг, 08–22 цаг :10 минутад, 3 цаг, 6 цаг, …) дээр дарах эсвэл cron бичнэ. Ажил бүрийн хажууд дараагийн эхлэх цаг харагдана. Нийтлэх ажлыг цуглуулахаас хэдэн минутын дараа тавина (анхдагч: сошиал :00, нийтлэх :10).

**Гадаад мэдээ** — гадаад багцын хамрах хоног (анхдагч 3), сэдвийн тоо (10), хуваарьт ажиллагаанд шаардах шинэ нийтлэлийн доод тоо (20), сайт бүрээс авах нийтлэлийн дээд тоо (40 — Yonhap, TASS зэрэг агентлаг 3 хоногт ≈ 100 мэдээ гаргадаг). Гадаад сэдэв дор хаяж 2 өөр хэвлэлд гарсан байх ёстой; нэг агентлаг л бичсэн мэдээ сэдэв болохгүй.

**Сонсох (аудио)** — уншигч сэдвийг сонсох эсэх, дуу хоолойн загвар (анхдагч `gemini-2.5-flash-tts`, монгол хэл дэмждэг), хоолой (анхдагч Charon; Kore, Puck, Aoede … ), өдөрт шинээр үүсгэх аудио хэсгийн дээд тоо (анхдагч 200). Аудио нь уншигч анх дарахад үүсч хадгалагдана; дахин тоглуулахад зардалгүй. Нэг хэсэг (нэг карт) ≈ $0.005, бүтэн сэдэв ≈ $0.02–0.05. Сэдвийг засахад тухайн хэсгийн аудио шинээр үүснэ.

**Сэдэв туслах (чат)** — уншигчийн чат идэвхтэй эсэх, загвар (анхдагч `gemini-3.5-flash-lite`, хамгийн хямд), өдөрт AI-аар хариулах асуултын дээд тоо (анхдагч 2000). Хайлт үнэгүй, зөвхөн олдсон мэдээнээс хариу бичихэд токен зарцуулна (асуулт ≈ $0.001); юу ч олдохгүй бол болон ⚡ товчнууд AI ашиглахгүй. Нэг төхөөрөмжөөс минутад 10-аас олон асуулт хүлээж авахгүй.

**Шинэ мэдээний доод тоо** — сүүлийн багцаас хойш ирсэн шинэ нийтлэл + пост үүнээс цөөн бол хуваарьт нийтлэх алгасна (анхдагч 15, 0 = үргэлж нийтлэх).

**Загварууд → Хүн таних** — мэдээнээс хүн таних AI загвар (анхдагч gemini-3.5-flash-lite, өдөрт хэдхэн цент).

Бусад: хамрах хоног, багц дахь сэдвийн тоо (1–50, зөвлөмж 45: уншигчийн **Халуун** таб хамгийн халуун 20-ийг, **Шуурхай** таб бүх багцын бүх сэдвийг (сэдэв бүрийг нэг удаа) хамгийн сүүлийн мэдээгээр эрэмбэлж, 20-оор нь гүйлгэхэд ачаалж харуулна; сэдэв олшрох тусам Gemini зардал өснө), сайт бүрээс авах нийтлэлийн дээд тоо, сошиал цуглуулалт (**үйлчилгээ** — платформ бүрийг аль үйлчилгээгээр татах; **ScrapeCreators 1 кредитийн үнэ** — худалдаж авсан багцын үнэ, жишээ нь $47 / 25,000 = 0.00188, Тайлангийн зардалд ашиглана; аккаунт бүрээс пост — нэг удаад авах дээд тоо; хагас задрал; **давхцал** — сүүлийн ажиллагаанаас өмнөх энэ хэдэн цагийн постыг дахин татаж like/share шинэчилнэ, анхдагч 1; их байх тусам зардал өснө), hot онооны жин (мэдээ / сошиал / хурд), Gemini загварууд, өдрийн токены хязгаар. Талбар бүрийн тайлбар: backend `docs/USER_GUIDE.md` → Тохиргоо.

## 8. Хэрэглэгчид (Супер админ, Админ)

- **Нэмэх** — **Нэвтрэх нэр** (латин жижиг үсэг, тоо, `. _ -`, 3–32 тэмдэгт), **Овог нэр**, **Эрх**, **Нууц үг** (8+ тэмдэгт). Нэвтрэх нэр, нууц үгээ ажилтанд аюулгүй замаар дамжуулж, нэвтэрсний дараа **Нууц үг солих**-ыг зөвлөнө.
- **Засах** — нэр, эрх солих; **Шинэ нууц үг** талбарыг бөглөвөл нууц үг солигдоно (хоосон бол хэвээр).
- **Идэвхтэй** унтраалга — бүртгэлийг түр хаана. Хаагдсан хэрэглэгч шууд гарч, дахин нэвтэрч чадахгүй. Ажлаас гарсан, түр чөлөөтэй ажилтанд үүнийг хэрэглэнэ.
- **Устгах** — бүртгэлийг бүрмөсөн устгана.
- **Сүүлд нэвтэрсэн** — идэвхгүй бүртгэлийг илрүүлэхэд тусална.

Хязгаарлалт:

- Админ зөвхөн редактор, модератор, сэтгүүлчийн бүртгэлийг үүсгэж, засаж, устгана. Админ, супер админы бүртгэлийг зөвхөн супер админ удирдана.
- Хэн ч өөрийн эрхийг өөрчлөх, өөрийгөө хаах, устгах боломжгүй — ингэснээр системд үргэлж дор хаяж нэг супер админ үлдэнэ.
- Эрхийн өөрчлөлт тухайн хүний дараагийн үйлдлээс шууд хэрэгжинэ.

## 9. Түгээмэл асуулт

**Цэс харагдахгүй байна.** Таны эрхэд хамаарахгүй. Шаардлагатай бол админд хандаж эрх нэмүүлнэ.

**Зассан гарчиг сайтад гарахгүй байна.** 5 минут хүлээгээд хуудсаа шинэчилнэ.

**Сэдвийг бүрмөсөн устгах уу?** Устгах боломжгүй — **Харагдах**-ыг унтраана. Энэ нь буцаах боломжтой.

**Шинэ сэдэв хэзээ гарах вэ?** Дараагийн хуваарьт **Нийтлэх** ажил дуусахад (хангалттай шинэ мэдээ байвал). Яаралтай бол редактор, админ **Вэб цуглуулах**, дараа нь **Нийтлэх** дарна.

**Нийтлэх ажил "Алгассан" гэж байна.** Шинэ мэдээ цөөн байсан тул токен хэмнэв. Хэвийн үзэгдэл. Шинэ багц заавал хэрэгтэй бол **Нийтлэх** гараар дарна.

**Сошиал пост цуглахгүй байна.** Ажиллагааны **Сошиал тайлан**-г харна. "TWITTERAPI_IO_KEY is not set" эсвэл "SCRAPECREATORS_KEY is not set" (төлөв skipped) бол хөгжүүлэгчид хандана; "402" эсвэл кредит дууссан гэсэн алдаа бол үйлчилгээний данс цэнэглэнэ; "partial" бол зарим аккаунт алдаатай — тэр аккаунтыг **Шалгах**-аар туршина (URL буруу, хаалттай профайл гэх мэт).

**Супер админы нууц үг мартагдсан.** Серверийн хандалттай хөгжүүлэгч `npm run create-user <нэр> superadmin <шинэ нууц үг>` командаар сэргээнэ (backend README).
