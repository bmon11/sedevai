# User guide (Delphi edition)

Reader and staff features are the same as in sedevmn; the original guide follows below. Differences in this edition:

- **One server:** the reader site, the admin (`/admin/...`) and the API (`/api/...`) all come from the same program on one port. There is no separate frontend process.
- **Speed:** pages and API calls are deliberately a little slow (about 130 ms or more per request). The server answers one request at a time, so a long admin action delays readers briefly.
- **Home tabs:** Шуурхай, Халуун, Гадаад, plus Сошиал.
- **Motion:** the animation on/off control is a ▶/⏸ button in the reader header.
- **Dark mode:** not available.
- **Unknown pages:** an unknown topic, edition or person shows a "not found" message inside the page.
- **Audio:** narration is MP3 when `lame` is installed, otherwise WAV.
- **Admin look:**
  - plain styling, with the sidebar as a slide-in drawer on phones;
  - the social posts table pages 50 at a time with prev/next;
  - forms show the server's error message instead of checking fields as you type.
- **Passwords:** accounts imported from the old Mongo database need a new password, set with `sedev create-user <username> <password> <role>`.
- **Running jobs:** a job started from Ажиллуулалт runs in the background. Only one run per kind can be running; starting a second one shows "already running" (409).

Setup, configuration and commands are in the [README](../README.md). Per-module notes are in [docs/modules](modules/).

## Сэдэв туслах (chat)

The chat lives **only inside a topic** (the topic reader, on the home page or at `/topics/[id]`); there is no chat button on the home page or other pages. Tap the round **chat button** at the bottom right of an open topic (or press **⌘J** / **Ctrl+J**):

- The header shows the topic's title. Quick questions: _Товчхондоо юу болсон бэ?_, _Яагаад энэ чухал вэ?_, _Цаашид юу болох вэ?_, _Хэн юу гэж хэлсэн бэ?_ — or type your own.
- Answers use **only this topic**: its analysis (**T1**) and its own articles (**A1**, **A2** …). Cited articles are shown as cards below the answer and open the original in a new tab.
- A question about something else is not answered (_Би зөвхөн энэ сэдвийн талаар хариулна_). If the topic's news does not contain the answer, the chat says so instead of guessing.
- Each topic keeps its own conversation while the browser tab is open; ↻ starts a new one.

## Install as an app (PWA)

The site can be added to the phone home screen and then opens full screen like an app, with the sedev.mn icon and name **Сэдэв**.

- **iPhone (Safari)**: Share button → **Add to Home Screen**.
- **Android (Chrome)**: the **Суулгах** button on the card below, or menu ⋮ → **Install app**.
- **Messenger / Facebook / Instagram** browsers cannot install apps: the card's **Safari-д нээх** / **Chrome-д нээх** button opens the page in the phone's browser first.

On phones, reader pages show a card **Сэдэв.мн-г утсандаа суулгах** 4 seconds after opening, with the steps for that phone. **Дараа** or × hides it for 14 days; it never shows inside the installed app. The installed app keeps the last opened pages and news data, so they open without internet (new editions need a connection). Admin pages are never stored offline.

## Admin

Open `/admin` and sign in with your **Нэвтрэх нэр** (username) and password. Opening any admin page while signed out goes to the sign-in page and returns you there afterwards.

The sidebar shows only the sections your role may use (**Агуулга**: Сэдвүүд, Тайлан, Хүмүүс, Ажиллагаа; **Тохиргоо**: Эх сурвалж, Сошиал, Задлах цэгүүд, Тохиргоо, Хэрэглэгчид). Buttons you may not use (e.g. **Одоо ажиллуулах** for journalists) are hidden; opening a forbidden page by URL shows **Хандах эрхгүй**. The sidebar can be collapsed with the arrow on its edge; on phones it opens from the menu button. The avatar at the top right shows your name, username and role, a link to the reader site, **Нууц үг солих** (change password) and **Гарах** (sign out).

# Pipeline and API guide (from sedev-backend)

The admin lives in the frontend at `/admin`. Log in with a username and password; the first superadmin is created by `npm run seed` (`ADMIN_USERNAME` / `ADMIN_PASSWORD`) or `npm run create-user`. What each role may do: `docs/ARCHITECTURE.md` → "Roles and permissions". Staff manual (Mongolian, per role): frontend `docs/ADMIN_MANUAL.md`.

## Ажиллагаа (Runs)

- Four jobs run on their own schedules (**Тохиргоо → Хуваарь**):
  - **Вэб** — collects news sites (free; default hourly from 07:00 to 21:00, resting overnight 22:00–07:00), then finds tracked people in the new articles (a few cents a day of Gemini Flash-Lite; see Хүмүүс).
  - **Сошиал** — fetches new posts of tracked accounts (X via twitterapi.io, Facebook/Threads via ScrapeCreators; costs credits; default hourly 08:00–22:00). Only posts after each account's last run / newest seen post (minus **Давхцал**) are fetched.
  - **Нийтлэх** — clusters, selects, writes wraps and publishes an edition (costs Gemini tokens; default hourly 08:10–22:10, 10 minutes after social). Uses the articles and posts already collected.
  - **Гадаад** — collects the foreign sources (region _Гадаад_) and publishes the foreign edition shown on the home page's **Гадаад** tab in one run: Цуглуулах → Бүлэглэх → Сонгох → Задлан шинжлэх → Нийтлэх (no people or social stages; costs Gemini tokens; default every 3 hours 08:30–20:30). Titles and wraps are written in Mongolian. Uses its own window, topic count and minimum from **Тохиргоо → Гадаад мэдээ**. From a terminal: `npm run job -- world`.
- The buttons **Вэб цуглуулах**, **Сошиал цуглуулах**, **Нийтлэх** start a job now. One run per job can be active; different jobs may run together.
- The **Төрөл** filter shows one job's runs. Status **Алгассан** (skipped): a scheduled publish found fewer new items than **Шинэ мэдээний доод тоо** since the last edition, so no tokens were spent and readers keep the current edition. A manual **Нийтлэх** always publishes.
- A publish run sends only new items to the AI and attaches them to the previous edition's topics where they continue the story. A topic with no new sources keeps its previous wrap (and staff edits) without an AI call; the run shows how many wraps were reused.
- Click a run to see its stage (Цуглуулах → Хүн таних → Сошиал → Бүлэглэх → Сонгох → Задлан шинжлэх → Нийтлэх), progress log, token usage, selected topics and a per-source report.
- **Бүлэглэх** keeps articles that name the same person (e.g. Х.Нямбаатар) together, and a person's own posts and videos next to the news about them, so a story spread over many sites is not lost on a busy day. **Сонгох** merges candidates about the same event into one topic (since 2026-10-20).
- Source report columns: **Олдсон** links found, **Шинэ** new articles stored, **Өмнө нь** already stored (skipped), **Хугацаанаас гадуур** outside the date window, **Огноогүй** no publication date found. Status `partial` means some articles failed; `failed` means nothing could be collected — check the source config.
- If a run fails (error shown in red), fix the cause and press **Үргэлжлүүлэх**. It continues from the failed stage; finished work is kept. Readers keep seeing the previous edition until a run publishes.
- Error "Model response truncated": the model ran out of output tokens. Press **Үргэлжлүүлэх** to retry; if it repeats, report it so the stage's token limit can be raised.
- Error `400 … INVALID_ARGUMENT`: Gemini rejected the request. A too-complex response schema is retried automatically without its list limits, so this error now means something else (e.g. a wrong model id in **Загварууд**). Check the settings and press **Үргэлжлүүлэх**.
- Error `429 … RESOURCE_EXHAUSTED` / "Quota exceeded": the Gemini key ran out of quota. The message says when it resets; press **Үргэлжлүүлэх** after that, or use a key with billing enabled.

## Эх сурвалж (Sources)

- The switch turns a site on or off for future runs.
- **Нэмэх** / **Засах** opens the source form:
  - **Холбоос олох** — where article links come from: HTML pages (home/category pages), RSS, sitemap, or a JSON API. Put one URL per line. **Нийтлэлийн замын загвар** is a regex for article paths, e.g. `/n/[a-z0-9]+`.
  - **Нийтлэл унших** — HTML: the CSS selector of the article body (title and date selectors are optional). JSON: the detail API URL with `{path}` or `{last}` and the field names.
  - **Шалгах** tests the form against the live site without saving: it shows how many links were found and parses three sample articles (title, date, text length). Save only when samples show ✓ and a date.
- Field reference: backend `docs/ARCHITECTURE.md` → "Source configuration".

- **Adding a site without selectors:** fill in name, slug, site URL and the home (or category) page under **Холбоос олох** and leave **Нийтлэлийн замын загвар** and the text selector empty, then press **Шалгах**. Without a pattern the site's RSS feed is used if it has one, otherwise links that look like articles (numeric id, dated path, short id or long slug; not category/tag/author pages). Without a selector the body is found automatically (the article's structured data, else the largest block of paragraphs). If the samples show "no date", set **Огнооны selector** to the element that shows the date (e.g. `.post-date`); if wrong pages are picked up, set a pattern such as `/n/\d+`.
- Built-in sources (`src/modules/sources/defaults.ts`, 74, all checked with `npm run probe` on 2026-10-12): each has a link rule and a starting **Жин** tier; most use the automatic body extraction. 17 earlier sites that were dead, not news or had nothing new for over a week were removed (e.g. etv.mn, trends.mn, chuham.mn).
- `npm run seed` only adds missing sources. `npm run sync-sources` rewrites name, URL, weight and the link/article rules of the built-in sources from `defaults.ts`, adds missing ones and turns off the removed ones; the on/off switch of the others is kept. Run it after updating the built-in list (it overwrites manual edits of those sources).

- **Бүс** (region): _Монгол_ sites feed the Вэб/Нийтлэх jobs and the Вэб / Медиа tab; _Гадаад_ sites feed the Гадаад job and tab. 5 foreign sites are built in (`src/modules/sources/world-defaults.ts`, since 2026-10-20): Reuters, CCTV (english.cctv.com), BBC News, The New York Times and Al Jazeera. BBC, Al Jazeera and CCTV pass the probe. NYT article pages often answer HTTP 403 and Reuters article pages answer HTTP 401 to bots, so these two yield few or no articles. The 20 earlier foreign sites (Guardian, DW, TASS, …) are turned off by `npm run sync-sources`. Listing links with a `/YYYY/MM/DD/` segment take that day as their publication date. Feed items are taken as articles even without a link pattern, so short ids like `/news/articles/c0jq2v` work. **Жин тооцоолох** covers Mongolian sites only; foreign sites keep their built-in tier.
- **Жин** (0.5–3, default 1): how popular/trusted the site is. It multiplies the site's share of a topic's hot score: 0.5 small or niche, 1 normal, 2 major outlet, 3 leading national outlet.
- **Жин тооцоолох** (button above the list, permission `sources`): recomputes every site's weight from the last N days (default 30). **Тооцоолох** shows old → new without saving; **Хадгалах** saves. A site gains weight when it appears in many published stories (reach), is among the first to report them (originality) and most of its articles end up in published topics (reliability); sites with few articles stay near their built-in tier (1 for sites added here). The result is on a log scale: the median site gets about 1, the best site 3 and the weakest 0.5, so the weight separates sites instead of giving many of them 3 (changed 2026-10-20). Recalculation overwrites manual weights. Same from the shell: `npm run recalc-weights -- --days 30 --dry-run` (drop `--dry-run` to save). Formula: `docs/ARCHITECTURE.md` → "Source weights".

## Сошиал (Social media)

Requires `TWITTERAPI_IO_KEY` (X) and/or `SCRAPECREATORS_KEY` (Facebook, Threads) in the backend `.env`; a platform whose service has no key is skipped (status `skipped` in the run's social report) and runs use the rest.

`npm run seed` adds 125 accounts (`src/modules/social/defaults.ts`; only missing ones are created): Facebook — 34 Mongolian news, TV and business pages (iKon, GoGo, News.mn, МОНЦАМЭ, Eagle News, Mongol TV, NTV, TV9, MNB, Bloomberg TV, Forbes Mongolia, Unread, …; `media`, weight 1–1.5) and 39 opinion leaders on social and political topics (journalists such as Н.Урантогтох, DeFacto, Б.Ганчимэг; politicians who post actively such as Ц.Элбэгдорж, Х.Баттулга, Н.Учрал, М.Нарантуяа-Нара; influencer Margadism; the DP, MPP and ХҮН party pages; MFCC, FactCheck.mn, Open Society Forum, the Bar Association and two podcasts as `page`; weight 0.5–2 by reach, follower counts pre-filled, each checked active in Oct 2026); X — iKon, MONTSAME and the 50 most-followed Mongolian X accounts (politicians as `official`, Baabar and DeFacto as `journalist`, the rest `influencer`; weight 1, У. Хүрэлсүх 2). Edit, disable or delete them like any account. Their posts appear after the next social job, or immediately with `npm run collect-social` in the backend.

Requests: at most 10 at a time; rate-limited (429) requests wait and retry. Each social run logs requests, credits and $ per platform; costs are summed in **Тайлан → Зардал**.

- **Аккаунт нэмэх**: platform (Facebook, X, Threads), profile URL (e.g. `https://www.facebook.com/ikon.mn`, `https://x.com/name`, `https://www.threads.com/@name`), display name, kind (journalist, page, influencer, media, official), **Жин** 0.5–3 and an optional follower count (Facebook does not report followers in posts; X and Threads fill it in automatically).
- **Шалгах** fetches up to 5 recent posts without saving (1–2 credits). Save when posts appear.
- **Постууд** tab: collected posts with likes/comments/shares and score.
- Each social job collects new posts of enabled accounts (after the last run minus **Давхцал**; a new account gets the whole window, up to **Аккаунт бүрээс пост**), refreshes metrics of recent posts, and the next publish gives the best new posts to topic selection. Posts that join a topic appear on its page as "Сошиал хариу" and can be cited.
- **Hot score**: topics are ordered by a 0–1 score from news coverage (site weights, each site once, reprints of another site's article count 30%), social activity (post engagement × account popularity; many accounts count more than one viral post; a post far above the account's usual engagement counts up to 4×; a post the news picked up afterwards — ≥2 sites within 24 h — counts 1.5×) and velocity (last 24 h vs. average, small topics stay neutral). Formula: `docs/ARCHITECTURE.md` → "Social media and the hot score".

## Хүмүүс (People)

- Readers: **Хүмүүс** (`/people`) ranks tracked public figures by news mentions in the last 7 days; each profile (`/people/<slug>`) shows mentions, attention index, coverage tone, share of voice, controversy, a 30-day trend and tabs Мэдээ (articles), Мэдэгдэл (quotes), Хэвлэл мэдээлэл (per outlet), Холбоо (people in the same articles), Сэдвүүд (Sedev topics).
- Admin **Хүмүүс** (permission `entities`: admin, editor): add a person or edit name, short name (as news writes it, e.g. `Н.Учрал`), title and **Хайх нэрс** (comma-separated word stems, capitalised: `Баттулг` finds Баттулга/Баттулгын). Keep titles current — the AI uses them to tell namesakes apart. Turning a person off hides the profile and stops new matching.
- New or changed names apply to articles collected from then on. To apply them to older articles, a developer runs `npm run extract-entities -- --rescan --days 30`.
- Tone is how the press portrayed the person (−1…+1, AI-read), not Sedev's rating of them.

## Сэдвийн ангилал (Topic sections)

Each topic gets a section (Улс төр, Эдийн засаг, Нийгэм, Дэлхий, Спорт, Соёл, Технологи) chosen by Gemini. Selection covers several sections, so large sports events (Asian Games, world championships) are included alongside politics; ads and PR are excluded.

## Тайлан (Report)

Analytics of published editions over the last 7/14/30/90 days: which stories and categories were hot each day. Topics of different editions about the same news are grouped into one **үйл явдал** (story) by shared sources. Score = hot score × 100. All staff roles may open it (permission `reports`). How it is computed: `docs/ARCHITECTURE.md` → Report.

**Зардал** card: per day the USD spent on social data services and on Gemini (list prices), with totals of requests, credits and tokens. Runs from before cost tracking count as $0.

## Задлах цэгүүд (Wrap points)

Each topic is analysed from every enabled wrap point, in this order. Defaults: Товчхондоо, Юу болов?, Тоон баримт, Яагаад анхаарал татаж байна? (also covers the background causes), Үйл явдлын дараалал, Байр суурь, үзэл бодол (each side's position includes the good and bad effects for it), Тодорхойгүй зүйлс.

- 2026-10-13: "Шалтгаан, суурь нөхцөл" was merged into "Яагаад анхаарал татаж байна?" and "Сайн ба муу тал" into "Байр суурь, үзэл бодол". On an existing database run `npm run merge-lenses` once (`-- --dry-run` first to see the count): it deletes the two wrap points, updates the two instructions, and folds the old texts of published topics into the merged cards (good/bad become the sides **Эерэг нөлөө** / **Сөрөг нөлөө**).

- Arrows change the order on the topic page. The switch enables or disables a point.
- **Засах** / **Нэмэх**: **Гарчиг** is what readers see; **Түлхүүр** is an internal id; **Хэлбэр** is how it is shown (text, list, key points card, key numbers tiles, timeline, perspectives, good/bad); **AI-д өгөх заавар** tells Gemini what to write for this point.
- Changes apply from the next run. Published topics keep the wrap points they were written with.
- Readers see the wrap points as consecutive cards of one story. Gemini first writes a short **storyline** for the topic, then every point follows it in order: each adds something new, none contradicts another, and all text is written in our own words from several sources (source sentences are never copied). Where sources disagree, the disagreement is stated as the positions of the sides. Write instructions that fit this flow (e.g. "Юу болов?" says what happened, "Яагаад анхаарал татаж байна?" builds on it) rather than instructions that repeat each other.
